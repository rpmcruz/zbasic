DIALOG (expression)
	returns current event in the buffer (FIFO style)

	returns (if expression = 0):
		0 - no event
		1 - button
		2 - edit field
		3 - window changed
		4 - window closed		
		5 - window update
		6 - return key
		7 - tab key
		8 - zoom-in
		9 - zoom-out
		10 - shift-tab
		11 - clear tab
		12 - left arrow
		13 - right arrow
		14 - up arrow
		15 - down arrow
		16 - other key

	returns the id (if expression = 1):
		0 - returns event type
		1 - button clicked
		2 - edit field clicked
		3 - inactive window clicked
		4 - window closed
		5 - window erased
		6 - edit field where return pressed
		7 - edit field where tab pressed
